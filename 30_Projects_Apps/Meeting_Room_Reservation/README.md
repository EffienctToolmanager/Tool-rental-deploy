# 🗓️ GEV Meeting Room Reservation System (사내 회의실 예약 시스템)
> **GEV Workspace Corporate Asset Hub - 극대화된 가시성의 실시간 전산망**

본 시스템은 **Room 1 (Bigger - 12인실)** 및 **Room 2 (Smaller - 6인실)**의 예약/점검 현황을 월간 달력 및 실시간 30분 단위 타임라인 그리드로 즉시 비교 검토할 수 있는 엔터프라이즈급 예약망입니다. 

---

## 🎨 Design System & Colors
* **Theme:** GEV Signature White & Evergreen Minimalist
* **Evergreen Base Color:** `#054141`
* **Layout:** Room 1 & Room 2 좌우 페어(Pair) 레이아웃 및 캘린더 그리드 - 타임라인 양방향 연동

---

## 🚀 [버튼 단위] 단계별 초정밀 배포 가이드

회사 PC의 까다로운 보안망 내에서 IT팀의 연동 승인 대기 없이 즉시 24시간 가동하기 위한 **버튼 클릭 단위 매뉴얼**입니다.

---

### 🌟 [배포 루트 A] 24/7 클라우드 무중단 배포 (쉐어포인트 탭 연동)
> **효과:** 회장님의 PC가 완전히 꺼지거나 퇴근하셔도, 전 사원이 24시간 언제든 실시간으로 예약할 수 있습니다.

#### [Step 1] 쉐어포인트에 업로드 및 보안 링크 생성
1. GEV 사내 **[쉐어포인트(SharePoint) 사이트]**에 접속합니다.
2. 왼쪽 메뉴 혹은 상단 탭에서 **[문서 (Documents)]** 라이브러리 폴더로 이동합니다.
3. 깃허브에서 다운로드받은 **[index.html]** 파일을 마우스로 드래그하여 문서함 빈 곳에 놓거나, 상단의 **[업로드(Upload)]** 버튼 ➔ **[파일(File)]**을 클릭하여 `index.html`을 선택합니다.
4. 업로드가 완료되면 파일명 우측의 **[링크 복사(Copy Link)]** 아이콘(체인 모양 🔗)을 클릭합니다.
5. 팝업창에서 **[복사(Copy)]** 버튼을 눌러 공유 링크 주소(URL)를 클립보드에 저장합니다.

#### [Step 2] MS Teams 채널 상단에 탭으로 이식
1. **[MS Teams 프로그램]**을 실행합니다.
2. 연동할 사내 공유 **[팀 채널 (예: 일반/General)]**을 선택합니다.
3. 채널 화면 최상단 우측에 있는 **[+ (탭 추가)]** 버튼을 클릭합니다.
4. 팝업창 검색란에 `웹사이트`를 입력하고, 파란색 지구본 모양의 **[웹사이트 (Website)]** 앱 아이콘을 클릭합니다.
5. 설정 화면에서 다음과 같이 입력합니다:
   * **탭 이름:** `회의실 예약망` (또는 `GEV Room Reservation`)
   * **URL:** 방금 [Step 1]에서 복사한 **[쉐어포인트 공유 링크 주소]**를 마우스 우클릭 ➔ **[붙여넣기]**합니다.
6. 우측 하단의 **[저장 (Save)]** 버튼을 클릭합니다.
7. **🎉 완공:** Teams 상단 탭에 회의실 예약망이 이식되어 24시간 상시 가동이 시작됩니다!

---

### 💻 [배포 루트 B] Teams 개인 사이드바 단독 앱 설치 (개인 전용)
> **효과:** 별도의 브라우저나 주소창 없이 오직 회장님 Teams 프로그램 왼쪽 메뉴에 전용 아이콘으로 고정됩니다.

1. 본 저장소 폴더에 패키징되어 있는 **[GEV_Room_App.zip]** 파일을 회사 PC 바탕화면에 복사해 둡니다.
2. **[MS Teams 프로그램]**을 실행합니다.
3. 왼쪽 최하단에 있는 **[앱 (Apps)]** 메뉴 아이콘(보라색 사각형 타일 모양)을 클릭합니다.
4. 왼쪽 메뉴 가장 밑바닥에 위치한 **[앱 관리 (Manage your apps)]** ➔ **[사용자 지정 앱 업로드 (Upload a custom app)]** 링크 버튼을 클릭합니다.
5. 파일 선택 창이 열리면, 바탕화면에 준비해 둔 **[GEV_Room_App.zip]** 파일을 선택하고 **[열기]** 버튼을 누릅니다.
6. 업로드 안내 팝업창이 뜨면 우측 하단의 **[추가 (Add)]** 버튼을 클릭합니다.
7. **🎉 완공:** Teams 왼쪽 사이드바 메뉴에 GEV 시그니처 아이콘이 생기며 회의실 예약 단독 창이 켜집니다! (아이콘 우클릭 ➔ **[고정(Pin)]**을 해두시면 앱이 상시 유지됩니다.)

## 🎮 [버튼 단위] 인앱(In-App) 사용 설명서

앱이 켜진 후 각 기능들을 완벽하게 조종하기 위한 클릭 단위 조작법입니다.

### 1. 예약 현황 확인 및 특정 일자 조회 방법
* **상단 현재 상태 바:** 프로그램 최상단에는 실시간 기기 시간을 파악하는 시계가 작동하며, **Room 1 / Room 2** 옆에 실시간 상태(`Vacant` / `In Use`)를 판정하는 점멸식 라이브 배지가 가동됩니다.
* **날짜 이동:** 월간 달력 우측 상단의 **[왼쪽 화살표( ◀ ) / 오른쪽 화살표( ▶ )]** 버튼을 클릭하여 이전 달/다음 달로 달력을 즉시 넘길 수 있습니다.
* **디테일 리뷰:** 달력 그리드 상의 **[특정 날짜 숫자 (예: 15일)]**를 마우스로 클릭하면, 하단의 **[Specific Date Timeline]**이 클릭한 날짜로 0.1초 만에 갱신되며 해당 일의 30분 단위 타임라인이 상세 렌더링됩니다.

### 2. 신규 예약 신청 방법 (일반 직원용)
1. 타임라인 우측 상단의 에버그린 색상 **[Reserve (예약)]** 버튼을 클릭하거나, 하단 타임라인 그리드의 원하는 빈 슬롯(예: `14:00 | Available`)을 직접 클릭합니다.
2. 팝업창이 열리면 아래 정보를 기입합니다:
   * **Organizer:** 예약자의 이름을 입력합니다. (예: `홍길동`)
   * **Department:** 소속 부서를 클릭하여 선택합니다. (예: `마케팅팀`)
   * **Subject/Title:** 예약 사유를 기입합니다. (예: `협력사 기술 교류 세미나`)
   * **Start Time / End Time:** 시작 시간과 종료 시간을 선택합니다. (기본 1시간이 자동 세팅됩니다.)
3. 우측 하단의 **[Confirm Booking]** 버튼을 클릭합니다.
4. **결과:** 달력의 해당 날짜 아래에 **에버그린 색상의 예약 신호 도트(Dot)**가 즉시 생성되며 타임라인이 예약됨 상태로 전환됩니다. 
   *(※ 만약 1분이라도 타 예약과 시간이 겹칠 시 충돌 팝업이 뜨며 저장이 차단됩니다.)*

### 3. Admin 모드 작동 및 예약 제한(잠금) 방법
1. 최상단 헤더 우측에 있는 **[Admin Mode]** 토글 영역을 클릭합니다. 
   * 클릭 시 스위치가 에버그린 색상으로 변하며 자물쇠 아이콘이 열립니다(`Unlocks`).
2. 타임라인에서 공사, 점검, 혹은 차단하려는 특정 시간대 슬롯을 클릭합니다.
3. 팝업창 하단에 새롭게 활성화된 **[🔐 Admin Locked]** 체크박스를 마우스로 클릭하여 체크합니다.
4. **[Confirm Booking]** 버튼을 누릅니다.
5. **결과:** 해당 날짜 아래에 **황색(Amber) 경고 도트**가 찍히며, 해당 시간은 사원들이 예약할 수 없는 **[🔐 Restricted / Closed]** 금지구역으로 실시간 원천 차단됩니다.
6. **삭제/강제 수정:** Admin 모드가 켜진 상태에서 기존 예약 블록을 클릭하면, 팝업창 좌측 하단에 빨간색 **[Delete]** 버튼이 생성됩니다. 이 버튼을 클릭하여 강제 예약 취소가 가능합니다.

### 4. M365 데이터 수동 백업 및 복구
* **내보내기:** 하단 컨트롤 패널의 **[Backup JSON]** 버튼을 클릭하면, 현재까지 누적된 모든 전산 예약 데이터 스트림이 텍스트 파일(`.json`)로 즉시 회사 PC 다운로드 폴더에 저장됩니다.
* **가져오기:** **[Restore Stream]** 버튼을 클릭 ➔ 파일 업로드 창에서 받아두었던 백업 파일을 선택하면, 단 1초 만에 전체 예약 데이터베이스가 완벽하게 복원 및 하이드레이션됩니다.
