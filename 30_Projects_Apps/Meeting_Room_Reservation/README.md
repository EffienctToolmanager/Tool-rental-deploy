# 🗓️ GEV Shared Calendar (사내 공유 예약 캘린더)
> **GEV Workspace - PC 없이 24시간 100% 무중단 구동되는 클라우드 전산망**

본 시스템은 모든 사용자가 하나의 화면에서 실시간으로 일정을 **조회(See), 등록(Add), 수정(Edit), 삭제(Remove)**할 수 있는 극도로 가볍고 직관적인 공유 예약 도구입니다.

**대표님의 PC가 꺼지거나 퇴근하시더라도 24시간 언제 어디서나 전 사원이 예약 현황을 실시간으로 확인하고 공유할 수 있도록 100% 서버리스 클라우드 방식으로 개편되었습니다.**

---

## 🎨 주요 특징
1. **100% PC 독립 가동 (No local PC needed):** 대표님 PC나 사내 웹 서버를 24시간 켜둘 필요가 없습니다. 완전한 클라우드 데이터베이스 연동 방식으로 작동합니다.
2. **실시간 양방향 공유 (Real-time Broadcast):** 별도의 새로고침 없이 5초마다 데이터가 자동 동기화되어, 다른 사용자가 일정을 추가/수정/삭제하면 내 화면에도 실시간으로 즉시 반영됩니다.
3. **완전 자율 운영:** 모든 직원이 동등한 권한으로 예약을 등록하고, 클릭 한 번으로 일정을 손쉽게 수정 및 삭제할 수 있습니다.

---

## ☁️ 24시간 무중단 클라우드 배포 및 실행 방법

사내 PC를 켜지 않고 24시간 영구 구동을 활성화하는 두 가지 완벽한 배포 방식입니다:

### 🌟 [루트 A] 사내 쉐어포인트(SharePoint) 탭 이식 (추천)
> **효과:** 별도의 주소 입력이나 브라우저 구동 없이, 회사 MS Teams의 상단 메뉴 탭으로 24시간 가동됩니다.

1. **쉐어포인트에 업로드:** 
   * GEV 사내 **[쉐어포인트 사이트] ➔ [문서(Documents)]** 라이브러리 폴더로 이동합니다.
   * `index.html` 파일을 드래그 앤 드롭으로 업로드합니다.
2. **공유 링크 생성:**
   * 업로드된 파일 옆의 **[링크 복사 🔗]** 아이콘을 클릭하여 공유 URL을 복사합니다.
3. **MS Teams 채널에 탭으로 고정:**
   * **[MS Teams 프로그램]**의 사내 팀 채널로 이동합니다.
   * 최상단 우측의 **[+ (탭 추가)]**를 누르고 **[웹사이트(Website)]** 앱을 선택합니다.
   * 복사했던 **[쉐어포인트 공유 링크 주소]**를 붙여넣고 저장합니다.
4. **🎉 완공:** Teams 상단 탭에 회의실 예약망이 이식되어 **전 사원의 PC가 꺼져도 마이크로소프트 클라우드를 통해 24시간 실시간 무중단 가동**이 시작됩니다!

---

### 💻 [루트 B] 로컬 HTML 단독 더블클릭 실행 (초간단)
> **효과:** 서버나 팀즈 연동을 거치지 않고, 바탕화면의 `index.html` 파일만 마우스로 더블클릭하여 바로 구동합니다.

1. 프로젝트 폴더의 `index.html` 파일을 복사하여 직원들 PC 바탕화면에 넣어줍니다.
2. 각자 바탕화면의 **`index.html`을 더블클릭**하여 켭니다.
3. **🎉 완공:** 브라우저에 화면이 뜨는 즉시 **24시간 작동되는 공용 클라우드 데이터베이스(KVDB)**에 자동 연동됩니다. 서로 다른 PC에서 바탕화면 파일만 켰을 뿐인데도, 5초 이내에 서로의 예약 상황이 완벽하게 실시간 공유 및 브로드캐스트됩니다!
